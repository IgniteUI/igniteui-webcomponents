# igc-card-media

A container component for card media content such as images, GIFs, or videos.
Use it in a card for visual content.

```ts
import { defineComponents, IgcCardMediaComponent } from 'igniteui-webcomponents';

defineComponents(IgcCardMediaComponent);
```

## Slots

- default: Renders the card media content (e.g., img, video elements).
