# igc-color-swatch-group

A labelled group of color swatches in a color panel or a color picker.

```ts
import { defineComponents, IgcColorSwatchGroupComponent } from 'igniteui-webcomponents';

defineComponents(IgcColorSwatchGroupComponent);
```

## Slots

- `label`: The label of the group. Its text also names the group.
- default: The swatches of the group.

## CSS parts

- `label`: The label element.
